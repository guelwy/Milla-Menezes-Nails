# Milla Menezes Nails 💅

Landing page desenvolvida para **Milla Menezes**, Nail Designer, com foco em apresentar seus serviços, trabalhos realizados e facilitar o contato para agendamentos.

O projeto foi criado como uma página institucional leve, responsiva e voltada principalmente para acesso por dispositivos móveis.

## ✨ Sobre o projeto

A página reúne as principais informações sobre o trabalho da Milla em uma única experiência:

* Apresentação da profissional
* Serviços oferecidos
* Galeria de trabalhos
* Seção sobre o atendimento
* Links para Instagram e WhatsApp
* Layout responsivo para diferentes tamanhos de tela
* Navegação por seções
* Animações sutis na galeria
* Suporte à preferência de movimento reduzido do usuário

## 🛠️ Tecnologias

* **HTML5** para a estrutura da página
* **CSS3** para estilização, responsividade e animações
* **JavaScript** para interações e animações da galeria
* **Google Fonts** para a tipografia

## 🎨 Design

A identidade visual utiliza uma combinação de tons claros e rosa, com tipografia elegante e elementos minimalistas para transmitir uma proposta delicada e profissional.

A página também utiliza diferentes famílias tipográficas para criar contraste entre títulos, textos e elementos de destaque.

## 📱 Responsividade

O layout foi desenvolvido para se adaptar a diferentes tamanhos de tela, incluindo:

* Desktop
* Tablets
* Smartphones

Em telas menores, o menu de navegação é adaptado para um formato compacto e as seções passam a utilizar uma organização em coluna.

## ♿ Acessibilidade e experiência

O projeto inclui suporte à preferência de **movimento reduzido** por meio de `prefers-reduced-motion`.

Quando essa preferência está ativa, as animações da galeria são desabilitadas e as imagens são exibidas diretamente, proporcionando uma experiência mais confortável para usuários que preferem reduzir efeitos de movimento.

## 🚀 Como executar

Não é necessário instalar dependências ou utilizar um servidor específico.

Basta clonar o repositório:

```bash
git clone https://github.com/guelwy/Milla-Menezes-Nails.git
```

Depois, abra o arquivo:

```text
milla-menezes-nails/index.html
```

Também é possível utilizar uma extensão como **Live Server** no VS Code para visualizar o projeto durante o desenvolvimento.
